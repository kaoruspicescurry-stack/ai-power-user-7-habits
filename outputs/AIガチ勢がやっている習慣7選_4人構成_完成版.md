# AIガチ勢がやっている習慣7選 構成案（4人版・完成版）

企画のゴール：AI初心者には「今日から1つ真似できる」、中級者には「単発利用から仕組み化へ進める」と感じてもらう。AIガチ勢を、難しい設定に詳しい人ではなく、AIへ仕事を渡し、検証し、使うほど自分向けに育てている人として描く。

チャンネル上の狙い：既存のAI活用動画に多い要約・文章作成の小技紹介ではなく、実演中に“状態が変わる瞬間”を見せる。音声が予定へ変わる、メモから触れるページが生まれる、人が席を離れても仕事が進む、誤情報が落ちる、修正が次の仕事へ残る、という視覚変化で維持率を作る。

想定視聴者：生成AIを検索・要約・文章作成には使っているが、それ以上の任せ方が分からない初心者〜中級者

想定尺：18〜22分／実演比率50〜60％

## 第6位｜ゼロから考えず、まず見本を作らせる（約2分30秒）

|---|---|---|
| 相談の限界 | 愛子さん「家族で週末旅行に行きたいんですけど、行きたい場所をメモしただけで、予定が全然まとまっていなくて」／佐藤くん「おすすめを順番に聞いていけば決まりませんか？」 | 多くの視聴者が経験する“旅行の相談だけ続いて決まらない”状況を作る |
| 素材 | 愛子さんが、行きたい場所、食べたい物、帰宅希望時刻だけを書いた手書きメモを見せる | 実物をカメラで見せ、「この雑さから形になる？」という不安を作る |

| 持ち帰り | 小出さん「簡単版は文章や資料の雑な初稿。ガチ勢版はクリックできる画面や動く試作品まで先に作らせます」 | AIの初稿は正解ではなく、直すための共通物と説明 |
| 次章への接続 | 小出さん「ただ、“いい感じに作って”では完成度が安定しません。次は終わった状態を伝えます」 | 第5位へ接続 |

## 第5位｜質問ではなく「終わった状態」を伝える（約2分30秒）

| 項目 | 話す展開 | 実際に教えたい内容・演出 |
|---|---|---|
| 左側の依頼 | 佐藤くん「引っ越しでやることを教えて」 | 左画面に一般的なチェック項目。期限、順番、家族分担、未確認事項がない状態を見せる |
| 右側の依頼 | 小出さん「2週間後に家族3人で引っ越せる状態にしてください。今日から当日までの日別チェックリスト、住所変更先一覧、荷造りラベル、当日の役割表を作る。契約・予約・解約は実行せず、必要なものだけ要確認にしてください」 | 指示全文を読ませず「誰向け・何が完成・合格条件・勝手にしない」の4色で表示 |
| 左右比較 | 佐藤くん「左は知識として読んで終わり。右は今日から何をするか決まっています」／愛子さん「“引っ越しについて教えて”ではなく、“引っ越せる状態にして”なんですね」 | 左を閉じ、右の4成果物を実際に開く。比較軸は最大4つ |
| 言葉の翻訳 | 小出さん「中級者向けには成果物・完了条件・停止条件と呼びます。でも最初は、誰のために、何を完成、満たす条件、勝手にしないこと、で十分です」 | 専門語は生活語の後にだけ出す |
| 持ち帰り | 佐藤くんが4項目テンプレートをスマホへ保存する | 視聴者がスクリーンショットできる固定画面を3秒出す |
| 次章への接続 | 愛子さん「仕事として渡せるなら、終わるまで見ていなくてもいい？」 | 第4位へ接続 |

## 第4位｜頼んだ仕事を裏で進めてもらう（約2分30秒）

| 項目 | 話す展開 | 実際に教えたい内容・演出 |
|---|---|---|
| 旧習慣 | 佐藤くんがAIの生成画面を見続け、終わってから次を依頼する／小出さん「これだとAIが速くなっても、人間の待ち時間は消えません」 | タイマーを出し、逐次実行の無駄を視覚化 |
| 3仕事を開始 | 小出さんが①住所変更先の調査、②荷造りチェックリスト、③家族への共有文を別々のタスクで開始 | 仕事の重複を避け、保存ファイルも分ける。3つの進捗バーを画面右へ固定 |
| 席を離れる | 小出さん「3つとも頼んだので、僕は撮影準備をします」／佐藤くん「本当に画面を閉じていいんですか？」 | 定点カメラで本人がPCから離れ、机を整える。画面録画だけにしない |
| くす丸のガチ勢視点 | くす丸「AIへ頼んだあと画面を見続けると、AIの処理時間を自分の待ち時間に変えているだけだよ。ガチ勢は、ぶつからない仕事に分けて別々に走らせ、その間に人間しかできない判断をする。速いAIを探すより、待たない仕事の組み方を作る方が効くんだよ」／佐藤くん「AIの速度より、自分が待たないことの方が大きいんだ」 | “非同期”という用語より先に、ガチ勢の時間設計として理解させる |
| 完了 | 戻ると3つの完了通知が並ぶ。逐次時間と並行時間を実測比較 | 数字は収録結果を使う。成功を決め打ちしない |
| 安全ルール | 小出さん「調べる・下書きは任せる。送る・公開する・消す・買うは、人間の確認で止めます」 | 難しい権限設定の独立章にせず、4動詞で覚えさせる |
| 次章への接続 | 佐藤くん「今の3つは別々の仕事でしたけど、1つの資料を複数のAIで作る時はどうするんですか？」 | 第3位の役割分担へ自然に接続 |

## 第3位｜AIを「作る係・疑う係・まとめる係」に分ける（約3分）

| 項目 | 話す展開 | 実際に教えたい内容・演出 |
|---|---|---|
| 前章からの確認 | 佐藤くん「さっきは3つの別仕事を同時に頼みましたよね。今度は1つの資料を作るなら、3つのAIに同じ質問をして答えを比べるんですか？」／小出さん「比べることもできますが、今回は3つに別の目的を持たせます」 | 唐突に多数決を出さず、前章の並列作業との違いから入る |
| 役割分担 | 小出さん「作る係は最新ニュース候補を5件集める。疑う係は公式発表・日付・数字を確認する。まとめる係は合格した情報だけで資料を作る」 | 3画面を人物のように見せ、担当札を付ける |
| 検証の瞬間 | 疑う係が、一次情報を確認できない1件を赤くして不採用にする | 警告音→BGM停止→公式ページとAIの主張を線で結ぶ。最重要の等速ポイント |
| リアクション | 佐藤くん「別のAIに“合ってる？”と聞くんじゃなくて、公式の証拠を探す役にするんですね」 | 初心者が役割分担の意味を自分の言葉で確認する |
| くす丸のガチ勢視点 | くす丸「同じ質問を3回して多数決を取っても、似た学習データから同じ間違いを出すことがあるよ。作る係は速さ、疑う係は証拠、まとめる係は分かりやすさみたいに、合格条件を変えるからチームになる。特に疑う係には“自分の意見”じゃなく、公式URL、日付、元の数字を出させるのが大事だよ」／佐藤くん「AIの人数より、違う目的を持たせることが重要なんだ」 | くす丸にガチ勢側の検証思想を語らせ、3人構成を守る |
| 持ち帰り | 小出さん「簡単版は、別チャットで“根拠が弱いものを挙げて、公式情報を示して”。ガチ勢版は調査・検証・編集を別の役割で動かします」 | 無料環境でも再現できる形へ着地 |
| 次章への接続 | 小出さん「役割を作っても、毎回同じ注意をしていたら疲れます。次は説明を残します」 | 第2位へ接続 |

## 第1位｜一度直したことを、次回のルールにする（約3分30秒）

|---|---|---|

| 別テーマで再試験 | 「AI初心者が最初にやめるべき習慣5選」とだけ渡し、新構成を作る | 追加指示なしで、困りごと・実演・簡単版・応用版が出るか確認 |
| 点数 | 修正前3/7→ルール更新後7/7。実際の出力で採点し、満点を捏造しない | スコアアニメーション。満たさなければ収録内で再修正する方が信頼が上がる |
| くす丸のガチ勢視点 | くす丸「チャットで“次から気をつけて”と言っても、その会話が終われば修正も消えやすいよ。ガチ勢は、今回だけの感想と、次の仕事にも使えるルールを分ける。“旅行ページは青くする”は今回の修正だけど、“未確認の日時は確定表示しない”は次にも使えるルール。AIを育てるって、褒めて会話を続けることじゃなく、再利用できる修正だけを説明書に残すことだよ」 | 今回固有の修正と汎用ルールの違いまで説明し、動画全体の決め台詞にする |
| 着地 | 小出さん「AIガチ勢は、毎日すごい指示を考えているのではありません。一度直したことを、次から直さなくていい形で残しています」 | “使うほどラクになる”へ回収 |

## まとめ｜7つは別々の小技ではなく、一つの流れ

| 進行 | 話す内容 | 狙い |
|---|---|---|
| 7習慣の連結 | 小出さん「そのまま話す。見本を作る。終わった状態を伝える。裏で進める。役割を分ける。説明書を持たせる。修正を次回のルールにする。この順番です」 | 7項目を暗記ではなく、AIとの働き方が進化する順番として回収 |
| 初心者の着地 | 佐藤くん「全部を一気にやらなくても、最初は60秒話して分けてもらうだけでいいんですね」 | 視聴後のハードルを下げる |
| 中級者の着地 | 愛子さん「中級者は、今の作業で毎回直していることを1つ、説明書へ追加するところからですね」 | 初心者と中級者に別々の最初の一歩を提示 |
| 中級者の補足 | 愛子さん「中級者は、新しいAIを探す前に、今のAIへ同じ説明を何回しているか確認すると、仕組みにできる場所が見つかりそうです」／小出さん「まさにそこです」 | 3人で振り返り、愛子さんが応用視点を回収する |
| CTA | 小出さん「まず今日、困っていることを60秒そのまま話し、“今日やる・後でやる・返信する・まだ決めない”に分けて、と頼んでみてください。7つのうち何個やっていたか、数字でコメントしてください」 | 行動CTAとコメントCTAを一つにまとめる |

## キャラ演出ルール

| ルール | 具体的な方針 |
|---|---|
| 小出さん | 全章の進行軸。先生だが上から評価しない。「僕も最初はこうしていました」と実体験で話す。専門語は生活語の後にだけ出す |
| 佐藤くん | 初心者が抱く疑問と、旧習慣の実演を担当。わざと無知にしすぎず、理解した内容を自分の言葉で言い直して視聴者の確認役になる |
| 愛子さん | 基礎説明を繰り返さず、仕事への応用、再利用、仕組み化を質問する。第7・第6・第5・第2位とまとめで使う。くす丸が話す章には出さない |
| くす丸 | 冒頭・第4位・第3位・第1位の4回。出る場面では2〜4文を使い、ガチ勢側の考え方と判断基準まで語る。正論7：嫌味3。父親いじりは1回まで |
| 同時話者数 | 1章の主要話者は最大3人。くす丸が出る章は「小出さん・佐藤くん・くす丸」とし、愛子さんを入れない |
| 掛け合い順 | 通常章は佐藤くんの疑問→小出さんの実演→愛子さんの応用。くす丸章は佐藤くんの疑問→小出さんの実演→くす丸のガチ勢解説→佐藤くんの言い直し |
| リアクション | 「すごい」だけで終わらせない。何が変わったかを言葉にする。「相談が完成物になった」「AIではなく公式情報で確認した」など |
| 画面優先 | 会話が実演を止めない。操作中は短い相づちにし、結果が出た瞬間に会話を戻す |
| 決め台詞 | 1本につき第1位のくす丸の一言だけを最大の決め台詞にする。各章で名言を作りすぎない |
