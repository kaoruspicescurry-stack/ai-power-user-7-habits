# AIガチ勢がやっている習慣7選

YouTube企画「AIガチ勢がやっている習慣7選」の構成案をまとめたリポジトリです。

## ファイル

- `outputs/AIガチ勢がやっている習慣7選_4人構成_完成版.md`：小出さん・佐藤くん・愛子さん・くす丸の話者と実演を割り振った完成構成
- `outputs/AIガチ勢がやっている習慣7選_初心者から中級者向け_最終構成案.md`：初心者〜中級者向けに再設計した最終版
- `outputs/AIガチ勢がやっている習慣7選_2026最新版_実演設計付き構成案.md`：最新動向と実演設計を反映した前段階版
- `outputs/AIガチ勢がやっている習慣7選_構成案.md`：参考動画分析をもとにした初期版

4人構成の完成版では、専門用語を生活語へ置き換え、各章を「身近な困りごと → 目に見える実演 → 初心者向け簡単版 → 中級者向け発展版」の順に統一しています。
